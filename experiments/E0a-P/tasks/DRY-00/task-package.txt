--- TASK BRIEF ---
Нужно подготовить инженерный план изменения существующей Ansible-роли process_exporter.

Целевое изменение:
- обновить управляемую версию process_exporter с 0.8.2 до 0.8.5;
- добавить поддержку целевых узлов x86_64 и aarch64;
- сохранить установку из внутреннего Nexus;
- включить изменение в существующий playbook exporters.yml.

Нужен только план: вопросы, assumptions, последовательность реализации, rollout/rollback и verification. Полный Ansible-код писать не нужно.

--- ARCHITECTURE CONTEXT ---
1. Целевые узлы работают на RHEL-compatible 9 и используют systemd.
2. В inventory присутствуют узлы с ansible_architecture=x86_64 и ansible_architecture=aarch64.
3. Имена артефактов во внутреннем репозитории используют architecture labels amd64 и arm64:
   - process-exporter-0.8.5.linux-amd64.tar.gz
   - process-exporter-0.8.5.linux-arm64.tar.gz
4. Target hosts не имеют доступа к GitHub и публичному Internet. Им разрешён HTTPS-доступ только к внутреннему Nexus.
5. process_exporter запускается от отдельного непривилегированного пользователя process_exporter.
6. Exporter слушает только 127.0.0.1:9256. Метрики забирает локальный monitoring agent.
7. На тех же узлах работает orders-api.service. Monitoring role не должна restart/stop/reload orders-api и не должна становиться runtime dependency приложения.
8. Playbook exporters.yml применяется к группе app_servers. Изменение сначала разворачивается на canary subset, затем на остальные узлы.
9. Functional success означает не только active systemd unit, но и доступность непустого /metrics на 127.0.0.1:9256.
10. Текущая production-версия 0.8.2 должна оставаться доступной для контролируемого rollback до окончания rollout.

--- ORGANIZATION POLICY ---
ART-01. Версия артефакта должна быть pinned. Использование latest или вычисление «последней версии» запрещено.
ART-02. Для каждой поддерживаемой архитектуры нужен утверждённый SHA-256. Checksum mismatch должен остановить converge до изменения активного binary.
ART-03. Новая версия сначала помещается в staging path. Замена активной версии должна быть контролируемой и не оставлять частично записанный executable.
ART-04. Artifact URL строится только из internal repository base URL, pinned version и явного architecture mapping.
CFG-01. Повторный converge при неизменном desired state должен завершаться без managed changes.
SVC-01. Изменение active binary или systemd unit должно приводить к restart только process_exporter.
SVC-02. Неизменные binary и unit не должны приводить к restart process_exporter.
SVC-03. Нельзя restart/stop/reload unrelated application services.
SEC-01. Service account остаётся непривилегированным и не получает login shell.
ROL-01. Rollout обязан иметь canary check, stop condition и documented rollback к предыдущей pinned версии.
OBS-01. После converge проверяются systemd state, listening endpoint и непустой metrics payload.
OWN-01. Изменение Prometheus/monitoring-agent scrape configuration не входит в эту задачу и требует отдельного owner decision, если окажется необходимым.

===== FILE: roles/process_exporter/tasks/main.yml =====
---
- name: Create process exporter group
  ansible.builtin.group:
    name: "{{ process_exporter_group }}"
    system: true

- name: Create process exporter user
  ansible.builtin.user:
    name: "{{ process_exporter_user }}"
    group: "{{ process_exporter_group }}"
    system: true
    shell: /sbin/nologin
    create_home: false

- name: Download process exporter archive
  ansible.builtin.get_url:
    url: >-
      {{ process_exporter_repository_base }}/{{ process_exporter_version }}/
      process-exporter-{{ process_exporter_version }}.linux-{{ ansible_architecture }}.tar.gz
    dest: /tmp/process-exporter.tar.gz
    mode: "0644"
    force: true
    checksum: "sha256:{{ process_exporter_checksums[ansible_architecture] }}"

- name: Install process exporter binary
  ansible.builtin.unarchive:
    src: /tmp/process-exporter.tar.gz
    dest: /usr/local/bin
    remote_src: true
    extra_opts:
      - --strip-components=1
  notify: Restart process exporter

- name: Render process exporter unit
  ansible.builtin.template:
    src: process_exporter.service.j2
    dest: /etc/systemd/system/process_exporter.service
    owner: root
    group: root
    mode: "0644"
  notify: Restart process exporter

- name: Enable and start process exporter
  ansible.builtin.systemd_service:
    name: process_exporter
    enabled: true
    state: started
    daemon_reload: true
